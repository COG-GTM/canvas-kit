# Canvas Kit 17.0 Upgrade Guide

This guide contains an overview of the changes in Canvas Kit v17. Please
[reach out](https://github.com/Workday/canvas-kit/issues/new?labels=bug&template=bug.md) if you have
any questions.

## Removals

Removals are deletions from our codebase and you can no longer consume this component. We've either
promoted or replaced a component or utility.

### getObjectProxy

The deprecated `getObjectProxy` utility has been removed from `@workday/canvas-kit-react/common`. It
was used to fall back to a default theme object when a partial theme object was provided. Canvas Kit
now themes components with CSS variables, so this fallback is no longer needed. If you still need to
merge a partial theme with defaults, use a plain object merge instead. For more information, view
our
[Theming Docs](https://workday.github.io/canvas-kit/?path=/docs/features-theming-overview--docs#-preferred-approach-v14).

`RecursivePartial` is still exported from `@workday/canvas-kit-react/common` (it is now exported
from the theming types module). It remains deprecated.

## Glossary

For an overview of the different packages we provide, please view our docs
[here](https://workday.github.io/canvas-kit/?path=/docs/guides-packages--docs).

### Main

Components in the Main package are stable and ready for production use.

### Preview

Components in the Preview package are mostly stable but may still receive breaking changes before
being promoted to Main.

### Labs

Components in the Labs package are experimental and may receive significant changes or be removed
entirely.
