## Removals

Removals are deletions from our codebase and you can no longer consume this component. We've either
promoted or replaced a component or utility.

### useThemeRTL

`useThemeRTL` (deprecated in v9) and its `ComponentStyles` type have been removed from
[Labs](#labs). They were the only exports of `@workday/canvas-kit-labs-react/common`, so that
subpath no longer exists. `@workday/canvas-kit-labs-react` also no longer depends on `rtl-css-js`.

Use
[CSS logical properties](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Logical_Properties)
instead, which flip automatically based on the document's `dir`.

```tsx
// Before (v16)
import {useThemeRTL} from '@workday/canvas-kit-labs-react/common';

const MyComponent = () => {
  const {themeRTL} = useThemeRTL();
  return <div css={themeRTL({marginLeft: '1rem', borderRight: '1px solid'})} />;
};

// After (v17)
import {createStyles} from '@workday/canvas-kit-styling';
import {system} from '@workday/canvas-tokens-web';

const myStyles = createStyles({
  marginInlineStart: system.space.x4,
  borderInlineEnd: `1px solid ${system.color.border.divider}`,
});

const MyComponent = () => <div className={myStyles} />;
```
