## Removals

Removals are deletions from our codebase and you can no longer consume this component. We've either
promoted or replaced a component or utility.

### Legacy Event Map Model Utilities

The following utilities were deprecated in
[v8](/docs/guides-upgrade-guides-v8-0--docs#utility-deprecations) and have been removed from
`@workday/canvas-kit-react/common`:

- Types:
  - `ToModelConfig`
- Functions:
  - `createEventMap`
  - `useEventMap`
  - `createEvents`

All of these have been replaced by `createModelHook`, which infers the config type, guards
(`should<Event>`) and callbacks (`on<Event>`) from the `defaultConfig`, `requiredConfig` and
`events` you return.

```tsx
// Before
const eventMap = createEventMap<Events>()({
  guards: {shouldOpen: 'open'},
  callbacks: {onOpen: 'open'},
});

const useDiscloseModel = (config: ModelConfig = {}) => {
  const [visible, setVisible] = React.useState(false);
  const state = {visible};
  const events = useEventMap(eventMap, state, config, {
    open() {
      setVisible(true);
    },
  });
  return {state, events};
};

// After
const useDiscloseModel = createModelHook({
  defaultConfig: {},
})(config => {
  const [visible, setVisible] = React.useState(false);
  const state = {visible};
  const events = {
    open() {
      setVisible(true);
    },
  };
  return {state, events};
});
// `shouldOpen` and `onOpen` are now valid config options
```

The deprecated `Model` type is still exported.

## Glossary

For an overview of the different packages we provide, please view our docs
[here](https://workday.github.io/canvas-kit/?path=/docs/guides-packages--docs).

### Main

Components in the Main package are stable and ready for production use.

### Preview

Components in the Preview package are mostly stable but may still receive breaking changes before
being promoted to Main.

### Labs

Components in the Labs package are experimental and may receive significant changes or be removed
entirely.
